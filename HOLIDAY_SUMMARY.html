🎌 สรุประบบประกาศวันหยุด — น้องใจดี

เพิ่มใหม่ 31 กรกฎาคม 2569 · ใช้ร่วมกันทุกช่องทาง (LINE OA / Facebook / Web Chat) — คนละระบบกับ "ตั้งเวลาปิดบอทซ้ำทุกสัปดาห์"

1. หลักการทำงาน

บอทไม่ปิดเลย ต่างจากระบบตั้งเวลาปิดบอทซ้ำทุกสัปดาห์โดยสิ้นเชิง — วันหยุดนี้แค่แนบข้อความแจ้งเตือนไปกับคำตอบปกติที่บอทตอบอยู่แล้ว


ไม่ใช่วันหยุด  → บอทตอบปกติ ไม่มีข้อความแจ้งอะไรเพิ่ม

อยู่ในช่วงวันหยุด  → บอทตอบปกติเหมือนเดิม + แนบข้อความแจ้งวันหยุดไปด้วย (ครั้งแรกของวัน/session เท่านั้น)


ตั้งเป็นวันที่เฉพาะเจาะจงได้ (เช่น 13-15 เม.ย. สงกรานต์) ไม่ใช่วันซ้ำรายสัปดาห์แบบระบบตั้งเวลาเดิม

2. ปัญหาที่ทำให้ต้องสร้างระบบนี้

ระบบ "ตั้งเวลาปิดบอทซ้ำทุกสัปดาห์" เดิม (/admin/schedule) รองรับแค่วันซ้ำรายสัปดาห์ ไม่รองรับวันหยุดนักขัตฤกษ์ที่เป็นวันที่เฉพาะเจาะจง


และเมื่อเข้าเงื่อนไข "ปิด" ตามระบบเดิม บอทจะเงียบสนิท ไม่แจ้งอะไรลูกค้าเลย — ทำให้ลูกค้าไม่รู้ว่าร้านปิดหรือระบบเสีย


ระบบประกาศวันหยุดนี้แก้ปัญหาตรงจุด: บอทยังทำงาน ลูกค้ายังได้คำตอบ แค่รู้เพิ่มว่าวันนี้เป็นวันหยุดอะไร

3. วิธีเข้าใช้งานหน้า Admin

1
เปิด browser ไปที่
https://line-bot-ai-theta.vercel.app/admin/holidays
2
ใส่รหัสผ่าน = ค่า ADMIN_SCHEDULE_PASSWORD ที่ตั้งใน Vercel (รหัสเดียวกับหน้า /admin/schedule ไม่ต้องตั้งใหม่)
3
กด เข้าสู่ระบบ → เข้าหน้าจัดการวันหยุดได้เลย

4. วิธีเพิ่มวันหยุด

1
เลือกวันที่เริ่ม และ วันที่สิ้นสุด (ตั้งวันเดียวได้ — ใส่วันเดียวกันทั้งเริ่มและจบ)
2
ตั้งชื่อวันหยุด — เช่น "วันหยุดสงกรานต์" (ไว้ดูอ้างอิงในรายการ ไม่ได้ส่งให้ลูกค้าเห็น)
3
พิมพ์ข้อความแจ้งลูกค้า — ข้อความจริงที่ลูกค้าจะเห็น พิมพ์เองได้อิสระเต็มที่
4
กด + บันทึกวันหยุด → มีผลทันทีเมื่อถึงวันที่ตั้งไว้

5. ตัวอย่างการตั้งวันหยุด

📌 ตัวอย่าง A — วันหยุดหลายวัน (สงกรานต์)

วันที่เริ่มวันที่สิ้นสุดชื่อวันหยุด
13/04/202615/04/2026วันหยุดสงกรานต์
ร้านปิดทำการวันที่ 13-15 เม.ย. เนื่องในวันหยุดสงกรานต์ กลับมาให้บริการวันที่ 16 เม.ย.ค่ะ 🙏

→ ลูกค้าที่ทักเข้ามาวันที่ 13, 14 หรือ 15 เม.ย. (ครั้งแรกของแต่ละวัน) จะเห็นข้อความนี้แนบไปกับคำตอบปกติ

📌 ตัวอย่าง B — วันหยุดวันเดียว (วันแม่)

วันที่เริ่มวันที่สิ้นสุดชื่อวันหยุด
12/08/202612/08/2026วันแม่
วันนี้เป็นวันแม่แห่งชาติ ทางร้านขอส่งความสุขให้คุณลูกค้าทุกท่านค่ะ 💐

→ ใส่วันที่เริ่ม-สิ้นสุดเป็นวันเดียวกัน = แสดงผลแค่วันนั้นวันเดียว

6. การจัดการวันหยุดที่มีอยู่

ปุ่มความหมาย
ปิดชั่วคราว วันหยุดนี้ถูกหยุดใช้ชั่วคราว — บอทจะไม่แนบข้อความนี้ (ข้อมูลยังอยู่ ลบไม่หาย)
เปิดใหม่ เปิดใช้วันหยุดนี้อีกครั้ง
ลบ ลบวันหยุดออกถาวร — ต้องตั้งใหม่ถ้าต้องการใช้อีก

7. ข้อสำคัญที่ต้องรู้

⏰ Timezone — เช็ควันที่ปัจจุบันด้วยเวลา Bangkok (UTC+7) เสมอ


🔁 แสดงครั้งเดียวต่อวัน/session — LINE และ Facebook แสดงข้อความนี้ครั้งแรกของแต่ละวันต่อ userId (ไม่แสดงซ้ำทุกข้อความ) ส่วน Web Chat แสดงครั้งแรกของแต่ละ session เพราะไม่มี userId ถาวร


🌐 ใช้ร่วมกันทุกช่องทาง — ไม่ต้องตั้งแยกทีละช่องทางแบบระบบตั้งเวลาเดิม ตั้งครั้งเดียวมีผลทั้ง LINE/Facebook/Web Chat


⚠️ ถ้าใช้ร่วมกับ "ตั้งเวลาปิดบอทซ้ำทุกสัปดาห์" (/admin/schedule) และวันที่ซ้อนทับกัน — ระบบปิดบอทจะทำงานก่อนแล้วเงียบสนิททันที ลูกค้าจะไม่เห็นข้อความประกาศวันหยุดเลย เพราะบอทหยุดตอบไปก่อนถึงจุดแนบข้อความ ควรระวังไม่ให้วันที่ 2 ระบบซ้อนกัน


✅ ถ้า Redis ล่ม — ระบบ fail-open บอทตอบตามปกติ ไม่แนบข้อความ (ไม่กระทบการตอบลูกค้า)
